# Groundwire v0.3 Governance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Goal:** Authenticate API and dashboard via Keycloak OIDC, isolate data by tenant, enforce register/approve policy, and expose a queryable audit register (JSON/CSV + run timeline).

**Architecture:** FastAPI validates bearer JWTs against Keycloak JWKS. Tenant and roles come from token claims. Policies are per-tenant rows. Audit records stay immutable; list/export filter by tenant. Dashboard uses Authorization Code + PKCE; the audit surface is the signal-box occurrence book, not a new visual world.

**Tech Stack:** Keycloak 26, PyJWT, existing FastAPI/Angular/D3.

**Spec:** `Groundwire_PRD.md` v0.3 (FR10–FR15)

## Global Constraints

- Visual world remains the signal box.
- Apache 2.0; Keycloak is Apache 2.0.
- Compose volumes, pytest TMPDIR, and Docker builder GC live on New Volume — not `/`.
- Tests run with `AUTH_ENABLED=false` except dedicated auth/policy/audit tests.

## Review Focus

- Missing bearer token is 401 when auth is on.
- Tenant B cannot read tenant A runs or audit rows.
- Operator cannot register agents; admin can.
- Approve actor is the authenticated username, not `anonymous`.
- CSV export contains the same rows as the JSON query.
