The problem

Agents are great in demos.
Fragile in production.

If you've run an agent against real systems, you've hit every one of these:

durability
💥

Long runs die silently

One process restart and the framework loses everything — your agent starts the whole task over, or worse, half-finished work with no record.

human-in-the-loop
🙋

“Approvals” are bolted on

An input() call isn't an approval gate. What happens when the approver doesn't respond for three days? Most frameworks have no answer.

compliance
📜

No real audit trail

When an agent sends an email or calls a paid API — who authorized it, under what policy, and why? In regulated contexts "we don't know" is a showstopper.

identity
🔑

Accountability is unanswerable

Without SSO and scoped policies, "which human is responsible for this agent's actions?" has no answer. (Full OIDC governance lands in v0.3.)

How it works

A control plane under your agent framework

Keep your LangChain, LangGraph, CrewAI, or custom code. Groundwire registers the contract — name, tools, approval policy — and runs it as a durable Temporal workflow.

  • Crash mid-run? The run resumes exactly where it stopped.
  • Gated step? The workflow durably pauses on a signal — indefinitely.
  • Every step transition, decision, and identity is recorded.
  • Approve, reject, or edit-and-approve the agent's proposed action.
terminal
# register an agent — the email tool needs a human
curl -X POST localhost:8000/v1/agents \
  -d '{"name":"ops-agent",
       "allowed_tools":["send_email"],
       "approval_policy":
         {"require_approval_for":["send_email"]}}'

# start a run — it plans, executes, then…
curl -X POST localhost:8000/v1/runs \
  -d '{"agent_id":"agt_01","payload":{...}}'

# …durably pauses before send_email
→ run awaiting_approval # and now it waits. For you.

# you decide — and it's on the record
curl -X POST .../runs/RUN_ID/approvals \
  -d '{"decision":"approve","actor":"you"}'
● run resumed → step executed → audit record written
The operator surface

A signal box, not a modal farm

Approving an agent's action should feel like pulling a brass lever on a red signal — deliberate, physical, unambiguous. The dashboard is an instrument panel: every run is a route, every gate is a held signal.
